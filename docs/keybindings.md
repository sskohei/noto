# キーバインド一覧

vim風のキーバインドを採用する。起動直後はスプラッシュ画面、それ以外は常にメイン画面(検索・タグ・メモ一覧・todoリストの4パネル)を表示する。

## スプラッシュ画面

| キー | 動作 |
|---|---|
| 何かキー | メイン画面へ進む(何も押さなければ約1.5秒で自動的に進む) |

## メイン画面(共通のグローバルキー)

検索パネルにフォーカスしている間を除き、どのパネルにフォーカスしていても以下のキーが使える(検索パネルにフォーカス中は、文字入力をクエリに反映するため `Esc`/`Enter` 以外はすべて素通しする)。

| キー | 動作 |
|---|---|
| `1` / `/` | 検索パネルにフォーカス |
| `2` / `t` | タグパネルにフォーカス |
| `3` | メモ一覧パネルにフォーカス |
| `4` | todoリストパネルにフォーカス |
| `n` | 新規作成(タイトル入力 → `$EDITOR` 起動)。フォーカス中のパネルがtodoリストならtodo、それ以外はメモを作成する |
| `dd` | 選択中の項目を削除(確認プロンプトあり)。フォーカス中のパネルがtodoリストならtodo、それ以外はメモを削除する |
| `?` | ヘルプ(このキーバインド一覧)を表示 |
| `q` / `Ctrl+C` | 終了(`Ctrl+C` はどのパネル・画面からでも終了する) |

## メモ一覧パネル(フォーカス中)

| キー | 動作 |
|---|---|
| `j` / `↓` | カーソルを1つ下へ |
| `k` / `↑` | カーソルを1つ上へ |
| `Enter` / `e` | 選択中のメモを `$EDITOR` で編集 |

## todoリストパネル(フォーカス中)

| キー | 動作 |
|---|---|
| `j` / `↓` | カーソルを1つ下へ |
| `k` / `↑` | カーソルを1つ上へ |
| `Space` | 選択中のtodoの完了/未完了を切り替え |
| `Enter` / `e` | 選択中のtodoを `$EDITOR` で編集 |

## 検索パネル(フォーカス中)

| キー | 動作 |
|---|---|
| 文字入力 | クエリに追加し、即座に一覧を再フィルタ |
| `Backspace` | クエリを1文字削除 |
| `Enter` | クエリを保持したままメモ一覧パネルにフォーカスを戻す |
| `Esc` | クエリをクリアし、全件表示にしてメモ一覧パネルにフォーカスを戻す |

## タグパネル(フォーカス中)

| キー | 動作 |
|---|---|
| `j` / `k` | タグ間を移動 |
| `Enter` / `Space` | タグの選択・解除(複数選択でAND絞り込み) |
| `Esc` | メモ一覧パネルにフォーカスを戻す |

## 削除確認プロンプト

| キー | 動作 |
|---|---|
| `y` | 削除を確定 |
| `n` / `Esc` | キャンセル |

## ヘルプ表示中

| キー | 動作 |
|---|---|
| `?` / `Esc` / `q` | ヘルプを閉じてメイン画面に戻る |
