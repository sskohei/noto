# 機能仕様

## コンセプト

「思いついたらすぐ書ける」「書いたものをすぐ見つけられる」の2点に特化したTUIメモ帳。フォルダ階層や同期などの複雑な機能は持たず、タグと全文検索だけで整理・発見を成立させる。

## 起動時の画面

`noto` を実行すると、まず "noto" のASCIIアートによるスプラッシュ画面が表示される。何かキーを押すか、約1.5秒経過すると自動的にメイン画面に切り替わる。

メイン画面はlazygit風に、検索欄・タグ一覧・メモ一覧・todoリストの4つのパネルを常時同時表示する構成(左サイドバー上段: 検索、左サイドバー下段: タグ、右メイン上部: メモ一覧、右メイン下部: todoリスト)。

- メモ一覧は更新日時の新しい順に並ぶ。各行にタイトル・タグ・更新日時を表示
- todoリストは未完了を先頭・完了済みを末尾に並べ、同グループ内は更新日時の新しい順。各行にチェック状態とタイトルを表示
- 検索欄・タグ一覧・todoリストはサイドバー/常設パネルとして表示され、`1`/`2`/`3`/`4` キー(または `/`・`t`)でパネル間のフォーカスを移動する
- フォーカス中のパネルは枠線・タイトル先頭の `▶` マークで判別できる
- メモ一覧パネル(3)とtodoリストパネル(4)は、フォーカスしている方が展開されて内容を表示し、フォーカスしていない方はタイトルと枠のみの縮小表示になる(検索・タグパネルにフォーカス中はメモ一覧が展開された状態になる)

## ユースケース

### 1. 新規メモを作成する

1. 一覧画面で `n` を押す
2. タイトル入力(空欄可。空欄の場合は本文の最初の行をタイトルとして扱う)
3. `$EDITOR` が起動し、テンプレート(frontmatterのみ書き込み済み)のMarkdownファイルを編集
4. エディタを閉じると保存され、索引が更新され、一覧に戻る

### 2. 既存メモを開いて編集する

1. 一覧で対象メモにカーソルを合わせ `Enter` または `e`
2. `$EDITOR` が起動し、既存の本文を編集
3. 保存して閉じると `updated_at` が更新され、索引に反映される

### 3. メモを検索する

1. `/` または `1` で検索パネルにフォーカスし、文字を入力
2. 入力するたびに一覧がインクリメンタルに絞り込まれる(タイトル・本文・タグを対象としたファジー全文検索)
3. `Esc` で検索をクリアし、`Enter` でクエリを保持したまま、それぞれメモ一覧パネルにフォーカスが戻る

### 4. タグで絞り込む

1. `t` または `2` でタグパネルにフォーカスする(常にタグ一覧が表示されている)
2. タグを選択すると、そのタグを持つメモだけに一覧が絞り込まれる
3. 検索語との併用が可能(タグ絞り込み + 全文検索のAND)。フィルタ中の条件はメモ一覧パネルのタイトルに表示される

### 5. メモを削除する

1. 一覧でメモにカーソルを合わせ `dd`
2. 確認プロンプトが表示される
3. 確定するとMarkdownファイルと索引エントリの両方が削除される(即時削除、ゴミ箱なし)

### 6. ヘルプを見る

- `?` でキーバインド一覧をオーバーレイ表示

### 7. todoを管理する

1. `4` でtodoリストパネルにフォーカスする(常にtodoリストが表示されている)
2. `n` で新規todoを作成する(タイトル入力 → `$EDITOR` が起動し、任意で詳細を本文に記述)
3. カーソルを合わせて `Space` を押すと完了/未完了を切り替える。完了したtodoは一覧末尾に移動する
4. `dd` で選択中のtodoを削除する(確認プロンプトあり、Markdownファイルと索引エントリの両方を即時削除)
5. `D` で完了済みのtodoをまとめて削除する(確認プロンプトに対象件数を表示、確定するとMarkdownファイルと索引エントリを即時削除)

## 非対話フロー(スコープ外)

CLI引数だけでメモを一発追加するような非対話コマンド(例: `noto "買い物リスト"`)はv1では持たない。詳細は [non-goals.md](non-goals.md) を参照。
