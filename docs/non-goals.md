# Non-Goals(v1でやらないこと)

「手軽に書く・素早く探す」という核となる価値に集中するため、v1では以下を意図的にスコープ外とする。将来的に検討する余地はあるが、実装前には改めて仕様を詰める。

- **クラウド同期・複数デバイス間共有**: メモはローカルファイルシステムのみに保存する。Git等で自分でバックアップ/同期する運用は妨げない
- **フォルダ階層による分類**: 整理手段はタグのみ。ネスト可能なフォルダ/ノートブックは持たない
- **ソフトデリート/ゴミ箱**: 削除は即時かつ確認プロンプトのみ。復元機能は持たない(誤削除対策が必要になった場合はGit管理を推奨する運用でカバーする)
- **Undo/変更履歴**: メモ本文の編集履歴やUndoスタックは持たない
- **プラグイン機構**: 拡張APIやプラグインローダーは持たない
- **内蔵テキストエディタ**: 本文編集はTUI内蔵ではなく `$EDITOR` に委譲する([spec.md](spec.md) 参照)
- **非対話CLIコマンド(例: `noto "メモ内容"` で一発追加)**: v1はTUI操作に一本化する
- **複数ユーザー/権限管理**: 単一ユーザーのローカルツールとして設計する

これらを実装する場合は、`docs/spec.md` と `docs/architecture.md` を先に更新し、レイヤ構成への影響(特にストレージ層・索引層の前提)を検討してから着手すること。
